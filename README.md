# Programa Fidelidade

Projeto acadêmico de desenvolvimento web, em evolução, desenvolvido com PHP, MySQL, HTML, CSS e JavaScript.

## 📌 Sobre o projeto

O Programa Fidelidade é um sistema web desenvolvido como projeto acadêmico com o objetivo de aplicar, na prática, conceitos de desenvolvimento web, programação, banco de dados e organização de sistemas.

O sistema permite o gerenciamento de clientes, pontos, categorias, prêmios e resgates, contando também com áreas destinadas ao gerenciamento administrativo e à interação dos clientes.

O projeto permanece em evolução, possibilitando a implementação de novas funcionalidades e melhorias ao longo do processo de aprendizagem.

## 🚀 Funcionalidades

- Cadastro, consulta, edição e exclusão de clientes
- Gerenciamento de pontos dos clientes
- Cadastro e gerenciamento de categorias
- Cadastro, consulta, edição e exclusão de prêmios
- Solicitação e gerenciamento de resgates
- Área administrativa
- Área de acesso do cliente
- Sistema de login e logout
- Controle de sessões
- Interface com HTML e CSS
- Interações utilizando JavaScript
- Integração com banco de dados MySQL

## 🛠️ Tecnologias utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## 📂 Organização do projeto

O projeto está organizado em diretórios de acordo com suas principais responsabilidades:

- `clientes/` — funcionalidades relacionadas aos clientes
- `config/` — configurações e conexão com o banco de dados
- `css/` — arquivos de estilização
- `img/` — imagens utilizadas no sistema
- `includes/` — componentes compartilhados entre as páginas
- `js/` — scripts JavaScript
- `premios/` — gerenciamento de prêmios
- `resgates/` — gerenciamento de resgates

## 🔐 Segurança

Na versão disponibilizada neste repositório, as senhas de usuários são armazenadas utilizando `password_hash()` e verificadas com `password_verify()`.

Credenciais reais e informações sensíveis não fazem parte deste repositório público.
